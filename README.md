# gc-tui

This is a command line interface for google classroom. It's built in rust using the tui framework [ratatui](https://ratatui.rs).

It aims to have the following functionality:
1. Have the same functionality as the webapp version of google classroom (for students)
2. Add extra helpful tools and shortcuts
3. Be extensible in a way that classroom natively isnt
4. Allow extensive theming

It is written in rust for compatibility on most systems with compiled binaries and for speed.

I am currently in the process of learning rust so there will likely be slow development. Sorry.
